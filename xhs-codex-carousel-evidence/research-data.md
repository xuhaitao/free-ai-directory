## 数据支持的内容结论

1. **用途题比抽象功能题更能引发评论。** “普通人拿 Codex 干什么”样本有 1336 条评论，评论区持续补充律师、教师、运营、个人知识管理等真实场景。
2. **路线图/长图教程更偏收藏。** 10 页 Vibe Coding 路线图收藏 4198，高于点赞 3092；32 页 Codex 新手教程收藏达到 1 万。
3. **真实体验、对比、避坑也有稳定需求。** 28 天真实感想、工具区别、会员封禁、成本等题目均进入可见头部样本。
4. **第一版最适合做“用途 + 可复制工作流”。** 它同时承接评论型需求和收藏型结构，且能自然延展成后续实战系列。

## 官方能力校准

OpenAI 官方 Codex use cases 包括理解代码库、处理表格数据、生成演示文稿、从想法做原型、浏览器测试以及将重复流程保存为技能。成品中的场景均按“有相应工具/连接器时才能跨应用执行”的边界表达，避免把未配置能力写成默认能力。

官方参考：[Codex use cases](https://developers.openai.com/codex/use-cases)
